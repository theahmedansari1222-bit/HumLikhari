# ہم لکھاری — انتظامی پینل (Staff Console)

یہ ایک الگ static web پینل ہے جو اسی Supabase project سے چلتا ہے۔ پینل صرف `is_staff()` وغیرہ سے کردار پوچھ کر مینو دکھاتا ہے؛ **اصل اجازت ہمیشہ ڈیٹابیس (RLS، column grants، triggers) نافذ کرتا ہے**، اس لیے بٹن چھپانا حفاظت نہیں، صرف سہولت ہے۔

## چلانا

1. `config.example.js` کو `config.js` کے نام سے copy کریں اور صرف Project URL اور **publishable key** لکھیں (secret / service-role key یہاں کبھی نہیں)۔
2. اسے کسی static سرور سے کھولیں، مثلاً ریپو روٹ سے `python3 -m http.server 8080` اور پھر `http://localhost:8080/admin/`۔
3. پہلے سے staff کردار والے اکاؤنٹ سے Google یا فون OTP کے ذریعے سائن اِن کریں۔
4. Production میں اسے **الگ ڈومین/سب ڈومین** (مثلاً `admin.example.org`) پر رکھیں، صارفین کی ایپ والے ڈومین پر نہیں؛ پھر وہی ڈومین `HUM_LIKHARI_ALLOWED_ORIGIN` میں شامل کریں۔ ہیڈرز کی فہرست `docs/DEPLOYMENT.md` میں ہے۔

## اہم رویّے

- **Review stamps ڈیٹابیس لگاتا ہے**: پینل `reviewed_by` / `reviewed_at` کبھی نہیں بھیجتا۔
- رپورٹ پر "مواد چھپائیں" مواد کو `removed` کرتا ہے (مصنف کو ڈیٹابیس trigger اطلاع بھیجتا ہے) اور رپورٹ خود بخود "کارروائی ہو گئی" ہو جاتی ہے۔ صارف کی رپورٹ پر اکاؤنٹ غیر فعال ہوتا ہے، حذف نہیں۔
- ٹکٹ کا **عوامی جواب** صارف کو اطلاع کے ساتھ دکھتا ہے؛ **اندرونی نوٹ** صرف اسٹاف کو۔
- کردار کی تبدیلی `manage-user-role` Edge Function کے ذریعے ہوتی ہے (ہینڈل یا UUID سے)؛ آپ اپنا admin کردار خود واپس نہیں لے سکتے، اور ہر تبدیلی audit میں درج ہوتی ہے۔
- پلیٹ فارم معاونت کی "تصدیق ہو گئی" صرف اصل ادائیگی کی تصدیق کے بعد منتخب کریں؛ پینل رقم کی خودکار تصدیق نہیں کرتا۔
- 30 منٹ غیر فعال رہنے پر سیشن خود سائن آؤٹ ہو جاتا ہے۔ ٹوکن refresh پر صفحہ دوبارہ لوڈ نہیں ہوتا، اس لیے لکھا ہوا جواب ضائع نہیں ہوتا۔
- `push-dispatch` کو صرف سائن اِن admin یا شیڈیولر (خفیہ `x-dispatch-secret` کے ساتھ) چلا سکتا ہے۔

## پہلا admin

پہلے اکاؤنٹ کا UUID Supabase Authentication > Users سے معلوم کریں، پھر SQL Editor میں `hum-likhari-backend/scripts/bootstrap-first-admin.sql` کی ہدایت کے مطابق پہلی `admin` role صرف project owner خود تفویض کرے۔ اس کے بعد کردار پینل ہی سے بدلیں۔

## حفاظتی نوٹس

- براؤزر میں صرف publishable key۔ Secret/service-role key یہاں کبھی نہیں۔
- پینل کا CSP `<meta>` میں ہے اور inline script/style نہیں چلاتا؛ clickjacking سے بچاؤ (`frame-ancestors`/`X-Frame-Options`) صرف HTTP header سے ممکن ہے، اس لیے وہ ہوسٹنگ پر لگائیں (`docs/DEPLOYMENT.md`)۔
- Staff اکاؤنٹس پر Supabase MFA (TOTP) لازمی کریں اور Google سائن اِن میں 2-step verification فعال رکھیں؛ فون OTP کو staff کے لیے واحد طریقہ نہ رکھیں (SIM-swap کا خطرہ)۔
- supabase-js CDN سے آ رہا ہے؛ production میں اسے اپنے ڈومین سے سرو کریں (vendoring) یا SRI hash لگائیں (`docs/DEPLOYMENT.md`)۔
